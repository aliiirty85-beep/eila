# دفتر امتیاز پنج‌دقیقه‌ای

با پایتون ۳٫۹ به بالا، در پوشهٔ پروژه اجرا کنید:

```sh
python3 eila.py config --zone Asia/Tehran --grace 0
python3 eila.py set yearly 2
python3 eila.py history
```

`set` فقط دوره (`daily`، `weekly`، `monthly` یا `yearly`) و سطح را برای پنج دقیقهٔ جاری انتخاب می‌کند. تکرار آن در همان بلوک انتخاب را جایگزین می‌کند؛ بلوک بدون انتخاب امتیاز ندارد. درجه از یک شروع می‌شود و به‌ازای هر بلوک قبلی با همان سطح و دوره در همان بازهٔ تقویمی یک واحد زیاد می‌شود. هفته از دوشنبه و ماه و سال بر اساس تقویم میلادی در منطقهٔ زمانی تنظیم‌شده محاسبه می‌شوند.

مهلت هر بلوک، پایان پنج دقیقه به‌علاوهٔ `grace` ثانیه است. تنظیمات پیش از اولین انتخاب قابل تغییرند. پس از پایان پنج دقیقه انتخاب بلوک قبلی دیگر در رابط قابل تغییر نیست. در نخستین اجرای بعد از مهلت، نتیجه در SQLite با زمان مؤثر همان مهلت قطعی می‌شود؛ نیازی به باز ماندن برنامه نیست. رکورد قطعی از طریق برنامه قابل حذف یا ویرایش نیست؛ این قفل محافظی در برابر مالک فایل پایگاه داده یا دستکاری ساعت سیستم نیست.

قاعدهٔ امتیاز، ترکیب `C(degree + level - 1, level)` است. برای آزمون: `python3 -m unittest`.

رابط بدون تایپ: `python3 eila_gui.py` (نیازمند Tkinter). فقط دوره و سطح را از فهرست انتخاب کنید. فایل داده کنار eila_gui.py نگهداری می‌شود.
