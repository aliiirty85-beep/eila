# ⏳ ایلا — ضرب‌الاجل، امتیاز و سطح

> 🌐 **آدرس برنامه:** https://aliiirty85-beep.github.io/eila/

یک برنامهٔ کامل و فارسی برای مدیریت زمان با **آلارم اجباری**:

- 📐 **امتیازدهی فقط با لول‌های مثلث خیام** — لولِ امتیازدهیِ هر فعالیت را خودت مشخص می‌کنی (۱ تا ۸)؛ امتیاز هر بار، یک خانه جلوتر از قطرِ همان لول در مثلث خیام می‌رود: «هر دفعه جلوتر، امتیاز بیشتر»
- 🧱 **بلوک ۵ دقیقه‌ای خودکار** — بلوک‌ها دقیقاً روی **مضرب‌های ۵ دقیقهٔ ساعت تهران** (۱۴:۰۵، ۱۴:۱۰، …) خودکار شروع و تمام می‌شوند؛ همهٔ امتیازها داخل بلوک ۵ دقیقه‌ایِ همان لحظه ثبت می‌شوند
- ⏰ **ضرب‌الاجل‌های روزانه / هفتگی / ماهانه** — برای هر فعالیت؛ اگر تا زمان ضرب‌الاجل انجام نشده باشد، آلارم پرقدرت می‌گیرد و دوره «از دست رفت» ثبت می‌شود
- 🔔 **آلارم اجباریِ مضرب ۵ دقیقه** — حین هر فعالیتی، دقیقاً روی مضرب‌های ۵ دقیقهٔ تهران: نوتیفیکیشن + صدا + ویبره. **همیشه فعال و غیرقابل خاموش‌کردن**
- 📊 **امتیاز بلوک‌ها به تفکیک ساعت و روز** — هر بلوک ۵ دقیقه‌ای با مجموع امتیازش در تاریخچه (روز → ساعت → بلوک) قابل مشاهده و بررسی است
- ⭐ **۸ سطح رتبه** از «مبتدی» تا «اسطوره» + تشخیص ارتقای سطح
- 📲 قابل نصب روی صفحهٔ گوشی (PWA) + کارکرد آفلاین
- 💾 ذخیرهٔ خودکار — با رفرش یا بستن صفحه، جلسهٔ بلوک‌ها و تایمر فعالیت از بین نمی‌رود

---

## 📐 قاعدهٔ امتیازدهی (فقط مثلث خیام)

دیگر «امتیاز دلخواه» وجود ندارد. هر فعالیت یک **لول امتیازدهی** دارد و دفعهٔ kاُمِ انجامش، امتیازِ خانهٔ kاُم از **قطر Lاُم مثلث خیام** را می‌گیرد:

| لول | دفعه‌ها | مثال |
|---|---|---|
| ۱ | ۱، ۱، ۱، ۱، … | هر بار ۱ امتیاز |
| ۲ | ۱، ۲، ۳، ۴، … | بعد از ۴ بار: ۱+۲+۳+۴ = **۱۰** |
| ۳ | ۱، ۳، ۶، ۱۰، … | بعد از ۳ بار: ۱+۳+۶ = **۱۰** |
| ۴ | ۱، ۴، ۱۰، ۲۰، … | بعد از ۲ بار: **۵** |
| ۸ | ۱، ۸، ۳۶، ۱۲۰، … | بعد از ۲ بار: **۹** |

نمونهٔ محاسبهٔ یک بلوک (همان‌طور که خواسته بودی):

- فعالیتی با **لول ۳** — دفعهٔ سومش که انجام شد → ۱+۳+۶ = **۱۰ امتیاز** داخل بلوک ۵ دقیقه‌ای
- خودِ **بلوک ۵ دقیقه‌ای با لول ۲** — چهار بار امتیاز گرفتن → ۱+۲+۳+۴ = **۱۰ امتیاز**
- جمع این‌ها → **۲۰ امتیاز برای آن بلوک** ثبت می‌شود

جدول کامل قطرها در تب **🏅 امتیاز** نمایش داده می‌شود و موقع انتخاب لول در فرم فعالیت، پیش‌نمایش زنده می‌بینی.

## 🧱 بلوک خودکار ۵ دقیقه‌ای (ساعت تهران)

- ساعت مبنا **Asia/Tehran** است؛ بلوک‌ها فقط روی مضرب‌های ۵ دقیقه شروع و تمام می‌شوند — دکمهٔ شروع/پایانِ دستی برای هر بلوک وجود ندارد.
- با زدن **«▶ شرکت در بلوک‌ها»**، از اولین مضرب بعدی، بلوک‌ها زنجیره‌وار خودکار شروع و تمام می‌شوند تا «⏹ پایان جلسه» بزنی.
- هر بلوک موقع بسته‌شدن، امتیازِ دفعهٔ بعد خودش را از مثلث خیام می‌گیرد (لول بلوک قابل تنظیم است — پیش‌فرض لول ۲).
- امتیاز تمام فعالیت‌ها هم **داخل بلوک ۵ دقیقه‌ایِ همان لحظه** ثبت می‌شود؛ مجموع هر بلوک در تاریخچهٔ «🧱 امتیاز بلوک‌ها» به تفکیک روز → ساعت → بلوک دیده می‌شود.

## ⏰ ضرب‌الاجل‌ها (روزانه / هفتگی / ماهانه)

- برای هر فعالیت می‌توانی ضرب‌الاجل تعریف کنی: **روزانه ساعت X**، **هفتگی روزِ هفتهٔ مشخص**، یا **ماهانه روزِ ماه مشخص** (اگر ماه آن روز را نداشته باشد، به آخر ماه clamp می‌شود).
- اگر تا لحظهٔ ضرب‌الاجل، فعالیت در آن دوره انجام نشده باشد: آلارم تکرارشونده + ویبره + نوتیف `requireInteraction` می‌گیرد و دوره «✗ از دست رفت» ثبت می‌شود؛ اگر انجام شده باشد «✓ انجام شد».
- روز و هفتهٔ ایرانی (شروع هفته از شنبه) و همهٔ زمان‌ها بر اساس ساعت تهران.

## 📥 ساده‌ترین راه: دانلود و اجرا (بدون هیچ دردسر)

> ❌ **دیگر پایتون/مسیر/سرور لازم نیست.** نسخهٔ پایتونی (tkinter) روی اندروید اجرا نمی‌شود — این نسخهٔ وب است و فقط با مرورگر کار می‌کند.

**روش ۱ — فقط یک فایل (پیشنهادی برای اندروید و دسکتاپ):**
1. فایل **`eila.html`** را دانلود کن (از همین مخزن، یا از داخل برنامه: تب ⚙️ تنظیمات → «📥 دانلود eila.html»).
2. روی فایل بزن تا با **کروم** باز شود (روی کامپیوتر: دابل‌کلیک).
3. دکمهٔ **«اجازه نوتیفیکیشن»** را بزن و **Allow** بده.
4. تب **⏱ بلوک** → **▶ شرکت در بلوک‌ها**. تمام! 🎉

این فایل همه‌چیز را داخل خودش دارد (استایل + کد + آیکون)؛ نه به پوشهٔ دیگری نیاز دارد، نه به اینترنت، نه به نصب چیزی.

**روش ۲ — نصب مثل اپ واقعی (برای آلارم کامل روی اندروید):**
1. همین آدرس را با کروم باز کن: https://aliiirty85-beep.github.io/eila/
2. منوی ⋮ → **Add to Home screen / افزودن به صفحهٔ اصلی**.
3. از این به بعد ایلا را از آیکون خودش باز کن.

> ⚠️ نکته: نوتیفیکیشن روی اندروید فقط وقتی کامل کار می‌کند که برنامه از آدرس اینترنتی (https) یا حالت نصب‌شده باز شود؛ در فایل تک‌فایلِ آفلاین، تایمر و صدا و ویبره کار می‌کنند ولی ممکن است نوتیف سیستمی نیاید. برای آلارم مطمئن، روش ۲ را استفاده کن.

## ▶️ اجرا در همین محیط (Arena)

1. روی لینک **Live Preview / پیش‌نمایش زنده** بالای همین صفحه بزن (سرور خودم روشن کرده‌ام).
2. دکمهٔ **«اجازه نوتیفیکیشن»** را بزن و **Allow** بده. ← بدون این قدم آلارم کار نمی‌کند!
3. برای اطمینان برو تب **⚙️ تنظیمات** → **«🚨 تست آلارم کامل»** — باید صدا، ویبره و نوتیف بگیری.
4. تب **⏱ بلوک** → **▶ شرکت در بلوک‌ها** (بلوک از مضرب ۵ دقیقهٔ بعدی خودکار شروع می‌شود) یا روی یک فعالیت بزن تا شروع شود.

## 🚀 انتشار روی GitHub Pages

سایت زنده: <https://aliiirty85-beep.github.io/eila/>

Pages روی این مخزن **فعال** است و از شاخهٔ `main` / پوشهٔ `/ (root)` منتشر می‌شود (فایل `.nojekyll` هم اضافه شده تا Jekyll در کار نباشد). هر تغییری که به `main` برود، ظرف چند ثانیه به‌صورت خودکار روی سایت می‌آید؛ نیازی به ورکفلو یا اقدام دستی نیست.

> تغییراتی که روی شاخه‌های کاری باشند تا زمان ادغام در `main` روی سایت دیده نمی‌شوند. برای تست همان شاخه، **Live Preview** این محیط را باز کن.

## 💻 اجرای محلی روی سیستم خودت

فایل‌ها را دانلود کن (کل پوشهٔ پروژه)، بعد در همان پوشه یکی از این دو راه:

**با پایتون (ویندوز/مک/لینوکس):**
```bash
python3 -m http.server 8000
```
*(در ویندوز اگر python3 نبود: `python -m http.server 8000`)*

**با Node.js:**
```bash
npx serve .
```

سپس در مرورگر باز کن: `http://localhost:8000`

> ⚠️ حتماً از طریق `localhost` باز کن، نه با دابل‌کلیک روی فایل — نوتیفیکیشن و سرویس‌ورکر فقط در `localhost` یا `https` کار می‌کنند.

## 📲 نصب روی گوشی (مثل یک اپ واقعی)

> ⚡ **راه سریع:** تب **⚙️ تنظیمات** → کارت «📲 نصب روی صفحهٔ گوشی». اگر مرورگر اجازه دهد، دکمهٔ **«📲 نصب ایلا»** ظاهر می‌شود و با یک کلیک نصب انجام می‌شود؛ وضعیت نصب نیز همانجا نمایش داده می‌شود. در آیفون و مرورگرهایی که دکمه را نشان نمی‌دهند، روش دستی زیر کار می‌کند.

**اندروید (کروم):**
1. صفحه را با کروم باز کن (لینک پیش‌نمایش را برای خودت بفرست).
2. منوی ⋮ → **Add to Home screen / افزودن به صفحهٔ اصلی**.
3. از این به بعد ایلا را از آیکون خودش باز کن — تمام‌صفحه و مستقل از مرورگر.

**آیفون (سافاری، iOS 16.4 به بالا):**
1. صفحه را در سافاری باز کن.
2. دکمهٔ اشتراک‌گذاری → **Add to Home Screen**.
3. نوتیفیکیشن آیفون فقط در حالت نصب‌شده کار می‌کند و ویبره پشتیبانی نمی‌شود.

## 🔔 تنظیمات گوشی برای ویبره و صفحهٔ قفل (اندروید)

- **تنظیمات گوشی → اپ‌ها → Chrome → Notifications**: روشن باشد و تیک **Lock screen** خورده باشد.
- **تنظیمات → صدا → Notification volume**: بلند باشد.
- اگر گوشی کروم را در باتری‌سِیوِر می‌بندد، کروم را استثنا کنید (Battery optimization → Chrome → Unrestricted).

## ⚠️ مهم‌ترین نکته

برنامهٔ وب تا وقتی **تبش باز باشد** آلارم می‌زند (بک‌گراند بودن تب کافی است). اگر مرورگر را کامل ببندی، دفعهٔ بعد که برنامه را باز کنی، ضرب‌الاجل گذشته شناسایی و آلارم با تأخیر نشان داده می‌شود؛ جلسهٔ بلوک‌ها هم اگر کمتر از یک ساعت غیبت باشد، بلوک‌های عقب‌افتاده را می‌سازد و بیشتر از آن، جلسه پایان می‌یابد. پس عادت کن تب را باز نگه داری یا برنامه را روی صفحهٔ گوشی نصب کنی.

## 📁 ساختار فایل‌ها

```
eila.html            ← ⭐ نسخهٔ تک‌فایل آمادهٔ دانلود (همه‌چیز داخل یک فایل)
index.html           ← صفحهٔ اصلی (فارسی و راست‌به‌چپ)
style.css            ← استایل (تم تیره، موبایل‌محور)
app.js               ← موتور بلوک خودکار تهران، امتیاز مثلث خیام، ضرب‌الاجل‌ها، آلارم
sw.js                ← سرویس‌ورکر (نوتیف + آفلاین)
manifest.webmanifest ← مانیفست PWA (نصب روی گوشی)
icons/               ← آیکون‌های برنامه
tools/build_single.py ← ساخت eila.html از فایل‌های بالا (python3 tools/build_single.py)
```

> بعد از هر تغییری در `index.html` / `style.css` / `app.js`، برای به‌روز شدن فایل تک‌فایل این دستور را بزن: `python3 tools/build_single.py`

## 🧪 تست سریع (برای توسعه)

```bash
npm install
npm test
```

دو تست بدون نیاز به مرورگر اجرا می‌شوند:

- **smoke.test.mjs** — رندر صفحه، جدول مثلث خیام، چیپ‌ها، شروع/توقف فعالیت، ثبت امتیاز داخل بلوک، کارت نصب PWA.
- **sim.test.mjs** — قواعد امتیاز مثلث خیام (۱۰+۱۰=۲۰)، هم‌ترازی مضرب‌های ۵ دقیقهٔ تهران، محاسبهٔ ضرب‌الاجل‌های روزانه/هفتگی/ماهانه (با clamp روز ماه).
